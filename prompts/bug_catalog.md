# Subtle bug-class catalog

Format per bullet: **Name**: WRONG behavior. *Spec must state*: rule. *Missed because*: reason. [src]
Sources were cited from known documentation and literature (no live search was run); verify links before external use.

## 1. transaction-recovery
- **Replay applies uncommitted tail**: recovery applies records after the last COMMIT marker. *Spec*: only transactions with a durable commit record are applied; the rest are discarded. *Missed*: happy-path logs end cleanly. [SQLite WAL](https://www.sqlite.org/wal.html)
- **Non-idempotent replay**: replaying twice (crash during recovery) double-applies increments/appends. *Spec*: recovery must be idempotent; state the LSN/seq skip rule. *Missed*: tests replay only once. [SQLite atomic commit](https://www.sqlite.org/atomiccommit.html)
- **Torn/partial record accepted**: a truncated final record or bad checksum is parsed as valid or stops replay of valid later data. *Spec*: define stop-at-first-invalid vs. skip, and truncate-after. *Missed*: needs a crash-shaped fixture. [Pillai et al. OSDI'14](https://www.usenix.org/conference/osdi14/technical-sessions/presentation/pillai)
- **Savepoint rollback leaks**: ROLLBACK TO restores values but not keys created/deleted, or discards the outer savepoint stack. *Spec*: nested savepoint semantics, including that the savepoint stays usable after rollback-to. *Missed*: only visible with nesting plus delete. [SQLite savepoint](https://www.sqlite.org/lang_savepoint.html)
- **Snapshot aliasing (shallow copy)**: snapshot/COW copies the top-level dict, so later nested mutation corrupts the snapshot. *Spec*: snapshots are immutable and isolated from later writes. *Missed*: passes with flat values. [Python copy docs](https://docs.python.org/3/library/copy.html)
- **Checkpoint/truncate ordering**: the log is truncated before the snapshot is durable, or the snapshot's LSN is not recorded, so recovery double-applies or loses entries. *Spec*: snapshot carries last-applied LSN; replay only entries with greater LSN. *Missed*: off-by-one at the boundary LSN. [ARIES](https://dl.acm.org/doi/10.1145/128765.128770)
- **Delete tombstone resurrection**: replay or compaction drops a tombstone, so an older value reappears. *Spec*: the last record per key wins, including deletes. *Missed*: needs set, delete, then recover with a snapshot. [Jepsen analyses](https://jepsen.io/analyses)

## 2. dependency-planning
- **Pre-release ordering**: `1.0.0-rc1` is treated as greater than `1.0.0`, or matched by `>=1.0`. *Spec*: the SemVer/PEP 440 precedence rule and whether prereleases are eligible. *Missed*: string/tuple compare looks fine. [semver §11](https://semver.org/#spec-item-11), [PEP 440](https://peps.python.org/pep-0440/)
- **Greedy newest-first without backtracking**: picks the highest version for the first requirer, then fails or picks a conflicting set when a satisfiable solution exists. *Spec*: must find a solution if one exists; define the preference order. *Missed*: needs a diamond with a late constraint. [PubGrub](https://nex3.medium.com/pubgrub-2fb6470504f)
- **Topological tie-break unstable**: ready nodes are emitted in set/hash order. *Spec*: the exact tie-break (e.g. lexicographic among ready nodes, Kahn with a min-heap). *Missed*: any valid topological order looks correct. [Kahn's algorithm](https://en.wikipedia.org/wiki/Topological_sorting)
- **Incremental invalidation stops at unchanged output**: dirtiness propagates only to direct dependents, or is not cut off when a rebuilt node's output hash is unchanged. *Spec*: transitive dirty rule versus early-cutoff rule. *Missed*: needs a depth of at least 3. [Build Systems à la Carte](https://www.microsoft.com/en-us/research/uploads/prod/2018/03/build-systems.pdf)
- **Diamond visited-set bug**: a visited set shared across branches suppresses re-checking a constraint, or one with an exact-version constraint on a shared dep is checked once. *Spec*: all constraints on a package must be intersected. *Missed*: tree-shaped examples pass.
- **Cycle reported or missed**: self-loops, or cycles reachable only through optional/dev edges, are mishandled. *Spec*: which edge kinds count and the cycle output format. *Missed*: cycle tests are usually 2-node. [Cargo resolver](https://doc.rust-lang.org/cargo/reference/resolver.html)
- **Caret/tilde on 0.x**: `^0.2.3` treated as `>=0.2.3,<1.0.0`. *Spec*: the exact range-expansion table. *Missed*: the general rule is well known; the 0.x special case is not. [Cargo semver](https://doc.rust-lang.org/cargo/reference/specifying-dependencies.html)

## 3. streaming-protocol
- **Split multi-byte unit at chunk boundary**: UTF-8 or a length prefix split across chunks is decoded per chunk. *Spec*: output must be identical for any chunking. *Missed*: tests feed whole messages. [IncrementalDecoder](https://docs.python.org/3/library/codecs.html#codecs.IncrementalDecoder)
- **Escape split across chunks**: an escape byte at chunk end is treated literally, or the escape state is lost. *Spec*: define the escape state machine, including an invalid escape. *Missed*: needs a chunk boundary exactly after ESC. [SLIP RFC1055](https://www.rfc-editor.org/rfc/rfc1055)
- **Checksum covers the wrong span**: the CRC includes the header or checksum field, or is computed over the escaped bytes instead of the unescaped payload. *Spec*: the exact covered bytes, init, and byte order. *Missed*: self-consistent encoder and decoder agree with each other. [CRC catalogue](https://reveng.sourceforge.io/crc-catalogue/)
- **Resync after corruption skips a valid frame**: after a bad frame the decoder discards the whole buffer, or advances past the next SOF found inside the bad frame's payload. *Spec*: resync rule (scan from byte 1 of the bad frame). *Missed*: single-corruption tests. [PPP framing](https://www.rfc-editor.org/rfc/rfc1662)
- **Chunked-length parsing leniency**: hex size with sign, whitespace, or overflow is accepted, or `0` terminator/trailers are mishandled. *Spec*: strict grammar. *Missed*: this is the root of many smuggling CVEs. [RFC 9112 §7.1](https://www.rfc-editor.org/rfc/rfc9112#name-chunked-transfer-coding), [Smuggling](https://portswigger.net/web-security/request-smuggling)
- **Buffer state not reset after error or EOF**: a decoder reused after an error carries stale partial bytes. *Spec*: reset semantics and what flush at EOF does with a partial frame. *Missed*: a fresh decoder per test.
- **Zero-length frame/empty chunk**: an empty payload is treated as end of stream or dropped. *Spec*: empty frames are valid and emitted. *Missed*: `if not data` idiom.

## 4. filesystem-migration
- **Rename cycles/swaps**: applying a->b, b->a sequentially clobbers a file. *Spec*: the plan is simultaneous; no data may be lost (temp-name staging). *Missed*: chains pass, cycles don't. [rename(2)](https://man7.org/linux/man-pages/man2/rename.2.html)
- **Path confinement by string prefix**: `startswith(root)` accepts `/root-evil`, or `..` is checked before normalization. *Spec*: confinement is on resolved components, and symlink targets count. *Missed*: obvious `../` tests pass. [Zip Slip](https://security.snyk.io/research/zip-slip-vulnerability), [CVE-2007-4559](https://nvd.nist.gov/vuln/detail/CVE-2007-4559)
- **Symlink followed or copied wrong**: a link is dereferenced on move/copy, or a link pointing outside the root is followed. *Spec*: links move as links; links are never followed for confinement. *Missed*: needs symlink fixtures. [CWE-59](https://cwe.mitre.org/data/definitions/59.html)
- **Resume replays completed steps**: the journal marks the step done before or after the effect, so resume repeats or skips it. *Spec*: journal order (write intent, apply, write done) and idempotent step semantics. *Missed*: needs an injected failure per step. [Pillai OSDI'14](https://www.usenix.org/conference/osdi14/technical-sessions/presentation/pillai)
- **Rollback is incomplete**: rollback undoes moves but not created directories, or runs in forward order. *Spec*: reverse order; the pre-state must be restored exactly. *Missed*: file-only assertions.
- **Overwrite and case-collision**: the destination exists (or collides case-insensitively) and is silently replaced. *Spec*: the conflict policy and the case-fold rule. *Missed*: Linux-only tests. [CWE-178](https://cwe.mitre.org/data/definitions/178.html)
- **Directory move ordering**: children moved after the parent is renamed, so paths go stale. *Spec*: the order of operations and whether the paths are pre- or post-move. *Missed*: depth-1 trees.

## 5. relational-transforms
- **NULL join keys match**: NULL = NULL treated as a match (as in pandas merge on NaN). *Spec*: NULL keys never match in inner/left joins. *Missed*: Python `==`/dict lookup makes None equal None. [modern-sql NULL](https://modern-sql.com/concept/null), [pandas.merge](https://pandas.pydata.org/docs/reference/api/pandas.merge.html)
- **NOT IN with NULL**: an anti-join via `not in` returns nothing, or the reverse is implemented. *Spec*: three-valued logic for NOT IN versus NOT EXISTS. *Missed*: people assume set semantics. [PG comparisons](https://www.postgresql.org/docs/current/functions-comparisons.html)
- **Duplicate-key fan-out**: join on a non-unique key dedups via a dict, losing rows, or aggregates after the join so sums multiply. *Spec*: the multiplicity (m x n rows) and aggregate-before-join order. *Missed*: unique-key fixtures. [Join fan-out](https://modern-sql.com/concept/join)
- **Aggregates ignore NULL**: AVG divides by row count, COUNT(col) counts NULLs, SUM of all-NULL gives 0 instead of NULL. *Spec*: NULL aggregate rules. *Missed*: idiomatic `sum()`/`len()`. [PG aggregates](https://www.postgresql.org/docs/current/functions-aggregate.html)
- **Interval join boundary**: half-open vs. closed overlaps (`a.end == b.start`) handled inconsistently, or adjacent intervals merged or not. *Spec*: [start, end) semantics and the merge-adjacent rule. *Missed*: tests use clearly disjoint intervals. [Allen's interval algebra](https://en.wikipedia.org/wiki/Allen%27s_interval_algebra)
- **Delete provenance**: deleting a source row doesn't retract derived rows that came only from it, or retracts rows that have other supporting sources. *Spec*: derived row exists iff at least one live support. *Missed*: single-support examples. [Provenance semirings](https://dl.acm.org/doi/10.1145/1265530.1265535)
- **Schema evolution default/promotion**: a new column's default is applied to old rows incorrectly, or a type promotion silently truncates. *Spec*: the reader-schema resolution table. *Missed*: tests use only the latest schema. [Avro resolution](https://avro.apache.org/docs/current/specification/#schema-resolution)

## 6. message-delivery
- **Stale ack accepted**: an ack from a previous lease holder is honored after redelivery. *Spec*: acks carry a fencing token/attempt number; stale acks are no-ops. *Missed*: single-consumer tests. [Kleppmann fencing](https://martin.kleppmann.com/2016/02/08/how-to-do-distributed-locking.html)
- **Lease expiry boundary**: `now > deadline` vs `>=` and extension counted from now vs from the old deadline. *Spec*: exact inclusive rule and the extend formula. *Missed*: off-by-one at the boundary. [SQS visibility](https://docs.aws.amazon.com/AWSSimpleQueueService/latest/SQSDeveloperGuide/sqs-visibility-timeout.html)
- **Dedup window and key**: dedup is keyed on the payload instead of the message ID, or entries never expire or expire too early. *Spec*: key, window, and whether dedup survives redelivery. *Missed*: no long runs. [Kafka semantics](https://kafka.apache.org/documentation/#semantics)
- **Redelivery loses order/attempt count**: a requeued message goes to the tail instead of its original position, or the attempt counter resets. *Spec*: requeue position and max-attempts-to-dead-letter. *Missed*: FIFO assumptions hold absent failures. [SQS FIFO](https://docs.aws.amazon.com/AWSSimpleQueueService/latest/SQSDeveloperGuide/FIFO-queues-understanding-logic.html)
- **Cancellation of in-flight message**: cancel of a leased message either deletes while the consumer still acks, or later redelivers it. *Spec*: the state-transition table for cancel x ack x expiry. *Missed*: transitions are tested in isolation.
- **Per-key ordering with head-of-line**: a nacked message lets later same-key messages be delivered first. *Spec*: per-key ordering holds across retries. *Missed*: needs two keys interleaved. [Kafka ordering](https://kafka.apache.org/documentation/#semantics)

## 7. resource-scheduling
- **Backfill delays reserved head job**: a backfilled job runs past the head job's reservation start. *Spec*: backfill must never delay the reservation; define the estimate used. *Missed*: it looks like a utilization win. [Slurm backfill](https://slurm.schedmd.com/sched_config.html)
- **Preemption restores wrong state**: a preempted job loses accumulated progress, or is re-queued with a new submit time. *Spec*: remaining work and queue position after preemption. *Missed*: only one preemption per test.
- **Tie-break nondeterminism**: equal priority resolved by dict order or a non-stable heap. *Spec*: full ordering key (priority, submit time, id). Python `heapq` is not stable. *Missed*: ties are rare in examples. [Sort stability](https://docs.python.org/3/howto/sorting.html#sort-stability-and-complex-sorts)
- **Precedence ignored on preemption/promotion**: a successor starts when its predecessor is preempted (not finished). *Spec*: only completion releases dependents. *Missed*: combined feature interaction.
- **Interval packing boundary**: `end == start` treated as overlap (or not) on a resource; greedy by start time instead of end time. *Spec*: half-open intervals and the optimality objective. *Missed*: touching intervals. [Interval scheduling](https://en.wikipedia.org/wiki/Interval_scheduling)
- **Bounded lookahead cutoff**: the window counts jobs vs time, or skips the job at position K. *Spec*: window definition, inclusive of K. *Missed*: off-by-one.
- **Priority inversion/aging**: aging applied once at enqueue, not each tick. *Spec*: the aging formula and when it is evaluated. [Mars Pathfinder](https://www.rapitasystems.com/blog/what-really-happened-software-mars-pathfinder-spacecraft)

## 8. configuration-semantics
- **Late-binding closure/lazy value**: lazy references capture the loop variable or are evaluated in the wrong scope. *Spec*: the scope in which a lazy expression is resolved. *Missed*: single-iteration tests. [Python FAQ](https://docs.python.org/3/faq/programming.html#why-do-lambdas-defined-in-a-loop-with-different-values-all-return-the-same-result)
- **Shadowing scope leak**: an inner definition mutates the outer scope, or a child scope assignment persists after the block. *Spec*: scoping and shadowing rules. *Missed*: Jinja-style quirks. [Jinja scoping](https://jinja.palletsprojects.com/en/stable/templates/#assignments)
- **Cycle detection false positive/negative**: a diamond (shared, non-cyclic) reference is flagged as a cycle because a global visited set is used, or a cycle through a default is missed. *Spec*: define cycle vs. repeated reference; the error format. *Missed*: path-stack vs visited-set confusion.
- **Memoization hides override**: a cached expansion is reused after an override or in a different context. *Spec*: whether expansion is per-context. *Missed*: order of lookups.
- **Merge precedence/deep-merge**: lists replaced vs. concatenated, `None`/false treated as unset, last-wins vs first-wins layering. *Spec*: the precedence order table and null semantics. *Missed*: `or` idiom drops falsy values. [Ansible precedence](https://docs.ansible.com/ansible/latest/playbook_guide/playbooks_variables.html#understanding-variable-precedence)
- **Operator associativity**: `a - b - c`, `**`, or `?:` chains parsed with the wrong associativity or precedence. *Spec*: the precedence table. *Missed*: two-operand tests. [Python power](https://docs.python.org/3/reference/expressions.html#the-power-operator)
- **Template escaping/expansion order**: `$$` escapes expanded after substitution, or substituted values re-expanded recursively. *Spec*: single-pass expansion and the escape rule. *Missed*: no values containing `$`. [string.Template](https://docs.python.org/3/library/string.html#template-strings)
- **Implicit typing**: `no`/`on`/`010` coerced to bool/octal. *Spec*: the type rules. [Norway problem](https://hitchdev.com/strictyaml/why/implicit-typing-removed/)

## Cross-cutting LLM-agent misses
- **Fix passes the shown example only**: patches the symptom for the given input and breaks a neighboring case. Evidence: tests in SWE-bench passed by incorrect patches ([SWE-bench+](https://arxiv.org/abs/2410.06992)); weak tests overestimate pass rates ([EvalPlus](https://arxiv.org/abs/2305.01210)).
- **State not reset between calls**: mutable defaults, instance caches, or module globals. [Python FAQ](https://docs.python.org/3/faq/programming.html#why-are-default-values-shared-between-objects)
- **Off-by-one at chunk/interval boundaries**: inclusive vs exclusive bounds; spec must say which.
- **Sort stability and tie-breaks**: relying on stable sort for tie order, `heapq` unstable, `key=` that omits a secondary key. [Sorting HOWTO](https://docs.python.org/3/howto/sorting.html#sort-stability-and-complex-sorts)
- **Truncation vs floor vs rounding**: `int(-3.5)` vs `//`, and banker's rounding in `round()`. [Python numeric types](https://docs.python.org/3/library/stdtypes.html#numeric-types-int-float-complex)
- **Idempotency on replay**: second application changes state.
- **Truthiness**: `if not x` treats 0/""/[] as missing.
- **Fixing one of two bugs**: agents stop after the first plausible defect; hidden tests exercise the second (combined-input bugs). Plant interacting bugs and require the written spec rule for each.
- **Over-fitting to docstrings/comments**: a comment that contradicts the spec misleads. Evidence: [LLM code-gen bug taxonomy](https://arxiv.org/abs/2407.06153).
